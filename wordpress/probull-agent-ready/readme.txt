Makes your WordPress site usable by AI agents (Gemini in Chrome, Claude, ChatGPT): WebMCP tool packs, llms.txt, origin-trial token, form annotations.

== Description ==
* Tool packs registered via document.modelContext: site info / FAQ / services / find page, enquiry + pricing, booking, structured quotes, restaurant menu + reservations.
* Every tool that sends personal data requires the agent to obtain user consent first; requests are e-mailed to you via a rate-limited REST endpoint.
* /llms.txt generated from your pages, posts and product categories.
* Chrome origin-trial token field so tools are live for real users during the trial.
* Declarative form annotations (toolname / tooldescription) for existing contact forms.

Pairs with the WebMCP Bridge plugin for WooCommerce cart/search tools. Free readiness check: https://probull.eu/ai-ready/
